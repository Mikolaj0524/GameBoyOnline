<h2 align="center">📖 Overview</h2>
<p align="center">
	The <b>GB.WASM</b> project acts as the vital glue between the pure C# emulator core (<b><code>GB/</code></b>) and the React web frontend (<b><code>GB.Frontend/</code></b>). By leveraging .NET WebAssembly support, it compiles the core emulation logic into highly optimized binary code that runs at near-native speed inside any modern browser.
</p>

<div align="center">

> [!NOTE]
> **Single File Architecture:** For simplicity and ease of maintenance, the entire module implementation-including core initialization, bindings, and entry points-is consolidated directly inside **`Program.cs`**.
</div>

<h2 align="center">🛠️ Architecture & Responsibilities</h2>
<div align="center">
<table align="center">
	<tr>
		<th align="center">Module / Area</th>
		<th align="center">Responsibility</th>
	</tr>
	<tr>
		<td align="center">🧠 <b>Core Wrapper</b></td>
		<td align="center">Initializes the LR35902 CPU, memory bus, PPU, and APU instances inside <code>Program.cs</code>.</td>
	</tr>
	<tr>
		<td align="center">🎨 <b>Graphics Interop</b></td>
		<td align="center">Extracts framebuffers generated by the PPU and exposes pixel data pointers to the TypeScript/JavaScript canvas renderer.</td>
	</tr>
	<tr>
		<td align="center">🔊 <b>Audio Sync</b></td>
		<td align="center">Passes raw audio samples from the APU buffer to the browser's Web Audio API.</td>
	</tr>
	<tr>
		<td align="center">⌨️ <b>Input Mapping</b></td>
		<td align="center">Receives joypad state updates from the web client and forwards button presses to virtual controller registers.</td>
	</tr>
</table>
</div>
